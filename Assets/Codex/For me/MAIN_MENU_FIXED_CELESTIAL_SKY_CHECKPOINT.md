# Fixed celestial sky for the main menu

The existing CelestialFieldSource and CelestialSkyRenderer now accept an optional fixed decorative sky profile. It saves a randomly chosen seed, frozen generation settings, bounds and observer position. Subsequent menu loads reconstruct the same celestial objects using the existing generator and render them using the existing sprites, glow and twinkle. Ambient stars, landmark stars, nebulae and deep-sky objects retain their existing generation rules.

This mode does not require a gameplay world or topography cache. It does not read gameplay navigation or daytime star visibility. It renders at full night star visibility without changing EnvironmentManager time, map knowledge or saves. Gameplay components without a fixed profile keep their current behavior. Constellation interaction is disabled for the decorative sky so menu mouse input cannot access gameplay chart knowledge.

No scene, prefab, existing settings asset or Inspector references were edited. The profile is intentionally generated by you, outside Play Mode, and saved as a project asset. It ships with the project, rather than becoming another player save. Generating again is an explicit action. A generator version mismatch requires deliberate regeneration instead of silently replacing the menu sky.

## Inspector tasks

1. In the Project window, Create → WorldMap → Celestial → Fixed Sky Profile. Name it MainMenuSky and store it wherever you keep menu assets.
2. Select that asset. Assign Assets/Defs/WorldMap/Celestial/CelestialGenerationSettings.asset as Generation Settings. Default bounds and observer (0,0) are suitable initially.
3. Use the profile Inspector's context menu → Generate And Save New Random Sky. A console confirmation should report its saved seed. This freezes the inputs; later changing the generation settings or authoring bounds does not alter the saved sky until you generate again.
4. Add a menu GameObject named CelestialSky. Add CelestialSkyRenderer; Unity also adds CelestialFieldSource.
5. On CelestialFieldSource, assign MainMenuSky to Fixed Sky. Topography Source and the ordinary Generation Settings can stay empty in this mode.
6. Duplicate Assets/Defs/WorldMap/Celestial/CelestialSkyProjectionSettings.asset into a menu-specific settings asset. Assign that copy to the renderer's Projection Settings. Assign the existing menu camera to Target Camera.
7. On the menu projection copy, set North Horizon Viewport Y to the menu waterline's viewport height (try 0.35) and South Zenith Viewport Y to 1.04. Keep ambient and landmark stars enabled. Use Background, order -100 for fallback sorting initially, and adjust relative to your authored sky/water if needed. Keep Legacy Stars Renderer empty unless the menu actually has an old star renderer you want replaced.
8. Save the scene and test. The stars have night visibility independently of gameplay time. The atmosphere/background material's night appearance remains your existing menu setup; this pass changes the celestial stars only.
